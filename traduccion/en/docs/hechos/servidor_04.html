Access and administration

Who can come in, who is in charge and who is not let in.

Who can create a character: entrada

It only affects whoever comes in for the first time: whoever already has a character can always come back in.

  • Values:
    • abierta: anyone who has the address.
    • clave: you need to know the entry password.
    • invitacion: a single-use code is needed.
  • Default: abierta.
  • It applies without restarting the server.

Entry password: clave

The password you need to know to create a character when entry is by password.

  • A text of up to 60 letters. It is saved as is in the file: do not show it to anyone.
  • Default: empty.
  • It applies without restarting the server.

Admins: admins

Player names that administer the server, separated by commas. They add to those named with the admin command.

  • A text of up to 600 letters.
  • Default: empty.
  • It applies without restarting the server.

The first account is an admin: primer_admin

With si, the first account created on the server is an admin: normally that is you.

  • Values: si or no.
  • Default: si.
  • It applies without restarting the server.

Banned names: vetados

Player names that cannot come in, separated by commas. They add to the accounts banned with the vetar command.

  • A text of up to 600 letters.
  • Default: empty.
  • It applies without restarting the server.

Kick for inactivity, in minutes: inactividad_minutos

Minutes without moving or doing anything after which a player is kicked to make room. With 0, never. Admins are not kicked.

  • A whole number between 0 and 1440.
  • Default: 0.
  • It applies without restarting the server.

Allow two sessions with the same identity: varias_sesiones

For testing only. By default, no: if someone comes in with their character from somewhere else, the previous session is closed.

  • Values: si or no.
  • Default: no.
  • It applies without restarting the server.

Game versions

Which versions of the game can play together on this server.

Check the game data of whoever comes in: comprobar_datos

With si, the server checks whether the world the incoming player's game brings is its own, that of another real version, or one changed with mods, and acts according to the following options. With no, it checks nothing: anyone comes in with whatever they bring, and the server does not catch up with the world of new versions.

  • Values: si or no.
  • Default: si.
  • It applies without restarting the server.

What to do with whoever brings data that cannot be checked: mundo_distinto

Players with mods that change the world, or with a version whose data the server cannot check. With a real version different from the server's you always get in, whatever you set here.

  • Values:
    • admitir: comes in and plays on what it has in common with the server; it is told what does not match, and what affects others is decided by the server with its world.
    • rechazar: does not come in: only the data of a real version is played.
  • Default: admitir.
  • It applies without restarting the server.

Versions that can play together: versiones

The server works with the world of the newest version it has seen, and talks to each game about what its version knows: a weapon or vehicle it does not have reaches it as the closest of its own.

  • Values:
    • compatibles: players with different versions of the game can play together, each with what their version knows.
    • iguales: only those with exactly the same data as the server get in.
  • Default: compatibles.
  • It applies without restarting the server.

Minimum game version: version_minima

The oldest version of the game that can come in, for example 1.7.0. Empty, any.

  • A text of up to 20 letters.
  • Default: empty.
  • It applies without restarting the server.

Who can bring a new world: actualizar_mundo

The game world (places, weapons, missions) is not tied to the server: the incoming player's game brings it. A server without a world takes the first incoming player's; if that one is not signed, it replaces it with the first signed one that arrives.

  • Values:
    • firmado: a newer version's is accepted from anyone if it is signed by the game's publisher.
    • admin: also, unsigned, from an admin: for modded servers.
    • no: never: the server keeps the world it has.
  • Default: firmado.
  • It applies without restarting the server.

Data and backups

Where everything is saved, how often and how many backups are kept.

Data folder: datos

The folder where everything is saved: characters, gangs, territories, vehicles, the certificate and the backups.

  • A text of up to 260 letters.
  • Default: datos_servidor.
  • Needs a server restart.

Save every so many minutes: guardado_minutos

Every how many minutes everything is saved to disk. Stopping the server always saves.

  • A whole number between 1 and 120.
  • Default: 1.
  • It applies without restarting the server.

Automatic backup, every so many hours: copia_auto_horas

Every how many hours the server makes a backup in the copias folder, inside the data folder. With 0, it makes none.

  • A whole number between 0 and 720.
  • Default: 24.
  • It applies without restarting the server.

Backups kept: copias_guardar

How many automatic backups are kept: when a new one is made the oldest are deleted. The ones you make by hand with another name are not touched.

  • A whole number between 1 and 365.
  • Default: 7.
  • It applies without restarting the server.

Save the log to a file: registro_archivo

With si, what the server says is also written to registro.txt, inside the data folder.

  • Values: si or no.
  • Default: no.
  • It applies without restarting the server.

Player-versus-player combat

The rules for fights, robberies and bounties.

Player-versus-player combat: pvp

With no, players cannot hurt, rob or steal from each other.

  • Values: si or no.
  • Default: si.
  • It applies without restarting the server.

Safe zones: zonas_seguras

With si, nobody can hurt anybody in hospitals, police stations, houses and inside venues.

  • Values: si or no.
  • Default: si.
  • It applies without restarting the server.

Allow passive mode: modo_pasivo

With si, each player can switch to passive mode: they neither hurt other players nor get hurt.

  • Values: si or no.
  • Default: si.
  • It applies without restarting the server.

Seconds of protection on arrival: proteccion

Seconds without being able to hurt or be hurt when coming in and when respawning.

  • A whole number between 0 and 600.
  • Default: 20.
  • It applies without restarting the server.

Loot for knocking down another player, as a percentage: botin

The percentage of pocket money lost by whoever falls to another player.

  • A whole number between 0 and 100.
  • Default: 10.
  • It applies without restarting the server.

Maximum loot: botin_max

The most that can be lost when falling to another player, in euros.

  • A whole number between 0 and 100000000.
  • Default: 5000.
  • It applies without restarting the server.

Robbing another player, as a percentage: atraco

The percentage of pocket money taken by whoever robs another player.

  • A whole number between 0 and 100.
  • Default: 15.
  • It applies without restarting the server.

Maximum robbery: atraco_max

The most that can be taken in a robbery of another player, in euros.

  • A whole number between 0 and 100000000.
  • Default: 1000.
  • It applies without restarting the server.

Seconds to rob a business: robo_segundos

The seconds you have to hold out at the door to empty the till of another player's business. The owner gets the alert.

  • A whole number between 1 and 600.
  • Default: 20.
  • It applies without restarting the server.

Bounty for knocking down an innocent: recompensa

How much, in euros, the bounty rises on whoever knocks down someone who was not defending themselves.

  • A whole number between 0 and 100000000.
  • Default: 500.
  • It applies without restarting the server.

Living world

Traffic, people on the street, the police and the characters the server runs.

Shared traffic: trafico

With si, the cars on the road are run by the server and are the same for everyone. With no, each player sees their own traffic.

  • Values: si or no.
  • Default: si.
  • It applies without restarting the server.

Cars per zone with players: trafico_max

How many cars the server runs, at most, for each zone of a town where there are players. For a few friends who go together it is the total number of cars in the town.

  • A whole number between 0 and 200.
  • Default: 8.
  • It applies without restarting the server.

Cars per town, at most: trafico_total

The cap on cars in the same town when there are players spread over many zones. With 0 there is no cap.

  • A whole number between 0 and 5000.
  • Default: 60.
  • It applies without restarting the server.

Patrol cars per town: patrullas

Server patrol cars that roam each town with players. With 0, none.

  • A whole number between 0 and 50.
  • Default: 1.
  • It applies without restarting the server.

Shared police: policia

With si, the wanted level, the chase and the arrest are run by the server, and everyone nearby sees and hears them. With no, each player's game runs them.

  • Values: si or no.
  • Default: si.
  • It applies without restarting the server.

Shared street people: peatones

With si, pedestrians are run by the server and are the same for everyone.

  • Values: si or no.
  • Default: si.
  • It applies without restarting the server.

Pedestrians per zone with players: peatones_max

How many pedestrians the server runs, at most, for each zone of a town where there are players.

  • A whole number between 0 and 200.
  • Default: 10.
  • It applies without restarting the server.

Pedestrians per town, at most: peatones_total

The cap on pedestrians in the same town when there are players spread over many zones. With 0 there is no cap.

  • A whole number between 0 and 5000.
  • Default: 80.
  • It applies without restarting the server.

Characters the server runs: personajes

Passers-by, pickpockets, gunmen, car thieves and robbers the server runs, the same for everyone. They only appear where there are players. With 0, none.

  • A whole number between 0 and 200.
  • Default: 6.
  • It applies without restarting the server.

Meters within which others are followed in detail: radio_detalle

Each player is told ten times per second where those closer than this distance are, and once per second where the others in their town are. It is what saves the most network and processor on servers with many people. With 0, everyone in detail all the time, which only suits a few people.

  • A whole number between 0 and 100000.
  • Default: 150.
  • It applies without restarting the server.

Economy and properties

The money the server recognizes, houses, businesses and vehicles.

The server keeps track of money: economia

With si, the server keeps track of each player's money and does not accept what it cannot justify.

  • Values: si or no.
  • Default: si.
  • It applies without restarting the server.

Maximum earnings per hour: ganancia_hora

The most that can be earned in one clock hour from jobs, sales, gambling and street loot, in euros. What the server itself gives does not count.

  • A whole number between 0 and 1000000000.
  • Default: 30000.
  • It applies without restarting the server.

Hours of earnings that can build up: ganancia_acumula

The hourly earnings a player does not use are not lost: they are kept up to this number of hours, also while they are away, so a good streak fits whole. With 1, they never have more room than one hour's.

  • A whole number between 1 and 48.
  • Default: 3.
  • It applies without restarting the server.

Repeatable jobs recognized per hour, of each kind: encargos_hora

Contracts, gym fights, robberies and car jobs that are really completed do not use up the hourly earnings: the server accepts them, up to this number per hour of each kind. With 0 it recognizes none and they all count against the hourly earnings.

  • A whole number between 0 and 1000.
  • Default: 6.
  • It applies without restarting the server.

Maximum pay recognized for a repeatable job: encargo_max

The most accepted from the pay of a single repeatable job, in euros. Anything above that counts against the hourly earnings.

  • A whole number between 0 and 1000000000.
  • Default: 15000.
  • It applies without restarting the server.

Maximum starting money: saldo_inicial

The most a new character can start with, in euros.

  • A whole number between 0 and 1000000000.
  • Default: 5000.
  • It applies without restarting the server.

Sale to the market, as a percentage: venta_mercado

The percentage of the price recovered by whoever sells their house or business to the market.

  • A whole number between 0 and 100.
  • Default: 70.
  • It applies without restarting the server.

Days without coming in to lose properties: propiedad_dias

Real days without coming in after which a player's properties go back on the market. Their share is kept for them.

  • A whole number between 1 and 3650.
  • Default: 30.
  • It applies without restarting the server.

Hours a vehicle lasts on the street: vehiculos_horas

Real hours a vehicle left on the street stays there.

  • A whole number between 1 and 8760.
  • Default: 12.
  • It applies without restarting the server.

Parked vehicles per player: vehiculos_por_jugador

How many vehicles each player can have parked on the street. When one more is left, the oldest disappears.

  • A whole number between 1 and 100.
  • Default: 3.
  • It applies without restarting the server.

Role-play and living together

The chat channels to play your character and what you hear from the other players.

Role-play channels: rol

With si, players have a channel to talk in character, heard only by those nearby, another to talk out of character, heard by the whole server, a command to describe what their character does and a profile line others can read. With no, only the usual chat remains.

  • Values: si or no.
  • Default: si.
  • It applies without restarting the server.

Meters what is said in character reaches: rol_metros

How far away what a player says in character, and the actions they describe, can be heard. What is said out of character always reaches the whole server.

  • A whole number between 5 and 2000.
  • Default: 30.
  • It applies without restarting the server.

Other players' car radio: radio_coches

With si, whoever is near another player's vehicle hears, faintly, the game radio station they have on. Only which game station it is gets shared: no music or anything personal ever travels. With no, nobody's radio is heard.

  • Values: si or no.
  • Default: si.
  • It applies without restarting the server.

Honest life

Permanent contracts with their paychecks and how shops treat each player according to their standing.

Paychecks for permanent contracts: nominas

With si, whoever signs a permanent contract at the job center gets their paycheck at the end of each period. The server pays it: it counts the shifts and sets the amount, which comes from the game data and does not use up the hourly earnings. With no, there are no permanent contracts on this server. The server's world must be from version 1.7.1 or later.

  • Values: si or no.
  • Default: si.
  • It applies without restarting the server.

Maximum pay per paycheck: nomina_max

The most the server pays for one period's paycheck, in euros, whatever the game world or a mod says.

  • A whole number between 0 and 1000000000.
  • Default: 1500.
  • It applies without restarting the server.

Contract shifts that count each day: nomina_turnos_dia

How many shifts of a permanent contract the server counts for a player on the same game day.

  • A whole number between 1 and 50.
  • Default: 3.
  • It applies without restarting the server.

Standing discounts in shops: trato_prestigio

With si, shops give a small discount to those with a good name among the neighbors, and charge extra to those with a very bad one, as when playing offline on the soft level. Only players with version 1.7.1 or later notice it. With no, everyone pays the same.

  • Values: si or no.
  • Default: si.
  • It applies without restarting the server.
